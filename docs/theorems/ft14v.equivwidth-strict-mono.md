## 1. Statement

The statement is over bare real functions on $\mathbb R$; no physical units are encoded in the
Lean type.

### 1.1 Symbols

| Symbol | Lean name | Meaning |
|---|---|---|
| $\psi$ | `ψ` | line profile, a real function of frequency or wavenumber |
| $\tau$ | `τ` | scalar optical depth; the argument of `equivWidth` |
| $W_\psi(\tau)$ | `equivWidth ψ τ` | equivalent width, the integral of $1-e^{-\tau\psi(x)}$ over $\mathbb R$ |
| $a,b$ | `a`,`b` | two points in the domain $[0,\infty)$ used by strict monotonicity |

### 1.2 Definitions used

- `equivWidth` — for a profile $\psi$ and scalar $\tau$,

$$
W_\psi(\tau)=\int_{\mathbb R}\left(1-e^{-\tau\psi(x)}\right)\,dx .
$$

- `StrictMonoOn` — a function $f$ is strictly increasing on a set $s$ if $a,b\in s$ and
  $a\lt b$ imply $f(a)\lt f(b)$.
- `Set.Ici 0` — the closed interval $[0,\infty)$.

### 1.3 Hypotheses

- **H1** (`hψ0` binder) — $0\le \psi(x)$ for every $x\in\mathbb R$.
- **H2** (`hint` binder) — $\psi$ is integrable with respect to the Lebesgue volume measure on
  $\mathbb R$.
- **H3** (`hpos` binder) — $0\lt \displaystyle\int_{\mathbb R}\psi(x)\,dx$.

### 1.4 Conclusion

The map $\tau\mapsto W_\psi(\tau)$ is strictly increasing on $[0,\infty)$: for any two optical
depths $a,b$ in that interval,

$$
0\le a\lt b\ \implies\ W_\psi(a)\lt W_\psi(b).
$$

| Binder | Label | Note |
|---|---|---|
| `ψ` | V1 | implicit variable; constrained by H1–H3 |
| `hψ0` | H1 | non-strict pointwise nonnegativity, parsed as `(0 : ℝ → ℝ) ≤ ψ` |
| `hint` | H2 | `MeasureTheory.Integrable ψ MeasureTheory.MeasureSpace.volume`; kept for parity with `equivWidth_mono` |
| `hpos` | H3 | strict positivity of the Lebesgue integral; with H1 it makes the support of $\psi$ have positive measure |

`Set.Ici 0` is closed at $0$. `StrictMonoOn` uses the strict order on both the domain and the
values.

`equivWidth ψ τ` and `∫ x, ψ x` are Bochner integrals, and Lean assigns the value $0$ to the
integral of a non-integrable function. Under H1, H2 and $\tau\ge 0$ the integrand
$1-e^{-\tau\psi(x)}$ is integrable (`equivWidth_integrand_integrable`), so on the domain of the
conclusion $W_\psi(\tau)$ is the genuine integral. For $\tau\lt 0$ the Lean value can be the junk
$0$.

## 2. Physical meaning

The mathematical content is the strict monotonicity of a parametric integral. In spectroscopy,
if $\psi$ is a line profile and $\tau$ is the optical-depth scale of a homogeneous slab, so that
$\tau\psi(x)$ is the optical depth at spectral coordinate $x$, then $W_\psi(\tau)$ is the
equivalent width of the line: the area of the line relative to the continuum. The theorem says
that, for a nonnegative profile with nonzero area, increasing $\tau$ strictly increases this
area.

If $\tau$ is proportional, with a positive proportionality constant, to column density or path
length, the same statement gives a strict increase of the integrated line absorption with that
parameter [derivation, unchecked]. With a positive source function $S$ and $\tau=\kappa L$ with
$\kappa\gt 0$, the spectrally integrated emergent intensity $S\,W_\psi(\kappa L)$ would be
strictly increasing in $L\ge 0$ (FT-14 part (ii)); that composition is not a landed declaration
[derivation, unchecked].

## 3. Scope and validity

- **Idealizations encoded:** a single profile $\psi$ on all of $\mathbb R$; a scalar nonnegative

- **What it does NOT claim:** it does not claim strict increase for $\tau\lt 0$; it does not claim

  concavity, saturation bound, or numerical accuracy; it does not claim that a pipeline
  self-absorption model is physically exact; it does not claim that instrument convolution
  preserves strict monotonicity; and it is not FT-14 part (ii) (strict increase of
  $S\,W_\psi(\kappa L)$ in path length or density, not landed) and not FT-14 part (v) (transfer
  before the instrument, $W_\psi\le W_{R\star\psi}$ by Jensen, parked as
  FT14-conv-absorptance-le), despite the card id.
- **Hypothesis sharpness / non-vacuity:** H3 is necessary: if $\psi=0$ almost everywhere then
  $W_\psi\equiv 0$ [derivation, unchecked]. H1 is necessary for the conclusion, not only for the
  proof step: $\psi=2\cdot\mathbf 1_{[0,1]}-\mathbf 1_{(1,2]}$ has $\int\psi=1$ but
  $W_\psi(\tau)=2-e^{-2\tau}-e^{\tau}$, so $W_\psi(1)\approx-0.85\lt 0=W_\psi(0)$
  [derivation, unchecked]. H2 is implied by H3 alone, because under Lean's Bochner convention a
  non-integrable function has integral $0$ (`MeasureTheory.Integrable.of_integral_ne_zero`); the
  Lean docstring keeps it for parity with `equivWidth_mono` [derivation, unchecked]. A
  non-vacuous witness for H1–H3 is $\psi(x)=e^{-x^2}$, for which
  $\int_{\mathbb R}\psi(x)\,dx=\sqrt{\pi}>0$ [derivation, unchecked]. For the unit-area box
  profile, $W(\tau)=1-e^{-\tau}$ [proved: CflibsFormal.equivWidth_rectangular], which is strictly
  increasing, consistent with this theorem.

## 4. Proof idea

The proof fixes $0\le a\lt b$ and defines the pointwise gap

$$
d(x)=e^{-a\psi(x)}-e^{-b\psi(x)}.
$$

It rewrites

$$
W_\psi(b)-W_\psi(a)=\int_{\mathbb R}d(x)\,dx
$$

using `equivWidth`, `integral_sub`, and `equivWidth_integrand_integrable`. The gap is
pointwise nonnegative by `mul_le_mul_of_nonneg_right` and `Real.exp_le_exp` (`sub_nonneg` gives
$0\le d$), and $d$ is integrable by `Integrable.sub`. Its support is shown to equal
`Function.support ψ`; when $\psi(x)\ne 0$, $\psi(x)\gt 0$ by `lt_of_le_of_ne`, then
$a\psi(x)\lt b\psi(x)$ by `mul_lt_mul_of_pos_right` and $d(x)\gt 0$ by `Real.exp_strictMono`.
Then `integral_pos_iff_support_of_nonneg` transfers H3 to positive measure of the support, making
the integral of $d$ strictly positive. The conclusion follows by `sub_pos`.

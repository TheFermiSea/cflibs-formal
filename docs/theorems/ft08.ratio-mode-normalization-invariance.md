## 2. Physical meaning

The headline says that a common multiplicative factor on every recovered density cancels from a pairwise number-fraction ratio. In CF-LIBS terms, if calibration, closure normalization, or neutrality normalization multiplies all species densities by the same factor, a ratio-mode reading of species $a$ against species $b$ is unchanged [derivation, unchecked]. The identity itself is pure vector algebra — this is the headline statement itself.

The member gives the exact first $\beta$-derivative of an abstract two-stage log-ratio. In the reduced CF-LIBS reading, $\beta$ is an assumed inverse temperature, $\ln U_X$ is a log partition-function factor, $\ln S_X$ is a log Saha factor, and $\ln n_e$ is the log electron-density factor. The derivative separates the energy offset, the partition-function slopes, and stage-fraction terms [derivation, unchecked]. The theorem itself is only the chain rule — this is the member statement itself.

## 4. Proof idea

The headline rewrites both occurrences of `composition (fun t => c * N t)` by `composition_smul_invariant hc`, then cancels the common denominator using `div_div_div_cancel_right₀ hsum (N a) (N b)`.

The member builds the derivative of each logarithmic term. For the $a$-term it uses `hSa.fun_sub hNe`, `const_mul εa`, `exp`, `const_add 1`, and `log (by positivity)`; the $b$-term is analogous. The linear terms are combined from `hasDerivAt_id'`, `mul_const (Ea - Eb)`, `const_add L0`, and `hUa.fun_sub hUb` using `fun_add` and `fun_sub`. The final derivative equality is closed with `congr_deriv` and `ring`.

- **What it would change:** It would make normalization invariance and the first-order sensitivity formula explicit and checkable. This changes rigor, not measurement accuracy; it is not a claim that any ratio estimate becomes more accurate.

It asserts that `log_ratios` returns the same values to floating-point tolerance, and is falsified if any ratio moves beyond rounding. For the member, a smooth synthetic $\Delta$ (non-constant $\ln S$, $\ln n_e$) whose central finite difference disagrees with the section 1.6 formula beyond $O(h^2)$ would expose a transcription error in this card, not in Lean.

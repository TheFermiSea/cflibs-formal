## 2. Physical meaning

In the repo's single-stage forward model, a Boltzmann-plot ordinate is the logarithm of a line
intensity divided by the product of its degeneracy and the transition probability used in the
denominator; Ciucci 1999 is the model source for this ordinate and the Boltzmann-plot method
[cited: Ciucci 1999]. If the analyst's `A'` differs from the true `A` by an energy-affine log
factor, the ordinate gains the term `α + b·E_k`. The theorem shows that this term is absorbed
exactly: the `b·E_k` part by changing `1/(kB T)` to `1/(kB T) - b`, and `α` together with the
partition-function change by rescaling the density (the proof's witness is `N' = N·e^α·U(T')/U(T)`;
the statement asserts only existence). This absorption is the theorem's own content, not a
literature claim.

Thus the wrong-data ordinates of a plasma at `(T, N)` are identical, line by line, to the
correct-data ordinates of a plasma at `(T', N')`, so no function of these ordinates alone can
distinguish the two cases [derivation, unchecked]. For `b > 0` the shifted temperature is higher
(`T' > T`), and for `b < 0` it is lower [derivation, unchecked]. The slope-only shadow of this
fact, that the OLS slope of the wrong-data ordinates is `−1/(kB T)` plus the OLS slope of
`log(A/A')`, is already landed [proved: CflibsFormal.olsSlope_aliasing_A].

## 3. Scope and validity

The generated scope-tags line will be inserted by `scripts/gen_cards.py`; until then this paragraph
is a placeholder.

- **Idealizations encoded:** the statement is exact for the encoded single-stage forward map
  `CflibsFormal.lineIntensity` with Boltzmann populations; it assumes a finite nonempty line set,
  positive degeneracies, and the affine gauge relation. It does not encode instrument response,
  self-absorption, multi-stage Saha coupling, or a level-cutoff policy.
- **What it does NOT claim:**
  - It does not claim the identity holds for real plasmas outside the encoded forward map.
  - It does not claim an energy-affine gA error is actually present or common in a dataset.
  - It does not claim `b` is unidentifiable in all experimental settings; it only says the
    single-stage ordinates do not identify it.
  - It does not prove the grouped two-stage version, an `ln n_e` shift, or a composition-leakage
    bound.
  - It does not claim `Fcal` is positive, and at `Fcal = 0` the density witness is not pinned by
    the ordinate equality.
  - It does not claim measurement accuracy is improved; it is a gauge/non-identifiability result.
  - It does not model a wavelength-dependent instrument response.
  - It does not cover errors in the energies `E` or the degeneracies `g` (both are shared by the
    two sides), nor any non-affine component of a line-specific `A` error; only the energy-affine
    direction is shown to be a gauge.
  - It is stated for the photon-rate ordinate `ln(I/(gA))`; carrying it to the energy-intensity
    ordinate `ln(Iλ/(gA))` is [derivation, unchecked].
- **Hypothesis sharpness / non-vacuity:** H7 is exactly the condition that `1/(kB T) - b` is
  positive, so the witness `T' = 1/(kB * (1/(kB T) - b))` is positive [derivation, unchecked].
  A concrete non-vacuous instance is `ι = Fin 1`, `kB = T = N = Fcal = 1`, `g 0 = 1`,
  `E 0 = 0`, `A 0 = 1`, `A' 0 = exp(-α)`, and `b = 0`; then `T' = 1` and
  `N' = exp(α)` satisfy the conclusion [derivation, unchecked]. This degenerate instance never
  exercises the temperature shift, which is the content of the result. A nontrivial witness — two
  lines, `kB = T = N = Fcal = 1`, `g = 1`, `E = ![0, 1]`, `A = 1`, `α = 0`, `b = 1/2`,
  `A' k = exp(-E k/2)` — is Lean-checked in [scratch: evidence/ft09.affine-atomic-data-gauge/ft09_witness.lean]; H7 is
  `b·kB·T = 1/2 < 1`, and the temperature equation forces `T' = 2`. For `Fcal > 0`, the log
  equality pins `N'`; at `Fcal = 0` every intensity is `0`, both log arguments are `0`, and the
  ordinate clause holds for every `N'`, so the density content is empty there (checked in the
  archived statement-audit scratch ft09_probe.lean, P3).

## 4. Proof idea

The proof first shows `0 < 1/(kB*T) - b` from H1, H2, and H7 using `mul_pos`, `sub_pos`,
`lt_div_iff₀`, and `linarith`. It then supplies the witnesses `T'` and `N'` described in §3.
Positivity of `N'` follows from `partitionFunction_pos` for `T` and `T'`, together with
`positivity`. `T' > 0` is `positivity` from `0 < 1/(kB T) - b`. The temperature equation is a
`field_simp` identity. The line-by-line ordinate equality reduces to the helper
`ordinate_arg_eq`, which rewrites with H6, unfolds `CflibsFormal.lineIntensity`, `population` and
`boltzmannFactor`, turns the shifted exponent `−E/(kB T')` into `−E/(kB T) + b·E` with the private
helper `exp_shift` (`div_eq_mul_one_div`, then `ring`), and closes with `Real.exp_add`,
`Real.exp_neg` and `field_simp`.

## 5. Role in the composition-extraction pipeline

- **Current state:** The theorem is landed in `CflibsFormal/HeteroAtomicData.lean`. This card
  names one public pipeline anchor, `BoltzmannPlotFitter`; `status.pipeline` is `referenced`.
- **Proposed use:** It can serve as a formal constraint on calibration-layer design: any
  single-stage estimator or certificate that treats an energy-affine gA direction as identifiable
  from Boltzmann-plot ordinates alone should be rejected, or should require an external
  identifying input. For this single-stage statement that input is an independent temperature,
  since `b = 1/(kB T) − 1/(kB T')`. Whether an independent electron density or a known composition
  identifies `b` belongs to the deferred two-stage statement and is not established here.
- **What it would change:** It would change rigor, not accuracy: it makes the gauge direction
  explicit and testable, and it narrows the class of admissible single-stage identifiability
  claims. It would not improve measurement accuracy.
- **How it would be validated:** feed the fitter synthetic single-stage spectra generated at
  `(T, N)` with `A`, and read them with `A' = A·exp(−(α + bE))`. The fitted temperature must equal
  `T'` within float tolerance; a different value would show the fitter's ordinate or model is not
  the one formalized. In pipeline use, the result would be confirmed if a single-stage estimator
  cannot separate the gauge direction without an external input, and falsified if such an
  estimator succeeds using only the encoded ordinates.
